# Changelog

## 0.16.2

- В каталоге инструментов добавлены раскрывающиеся описания, а не только переход на AON. Встроенная панель показывает описания всех 36 кастомизаций; уточнены полные игровые условия кратких записей.
- Собственные кастомизации переведены в нативные bonus feat: выбранные улучшения появляются в бонусных способностях character-листа компаньона без дублирующих Actions или Rules. Способности фамильяра, поддержка и манёвры сохраняют свой штатный тип.
- Старые неизменённые Actions, созданные модулем, безопасно заменяются после создания нового feat; допустимый выбор брони переносится. Ручные и изменённые копии защищены. ID embedded Item при смене типа меняется, UUID компендиума сохраняется.
- Общая проверка релизного манифеста требует постоянный latest-адрес и ZIP той же версии. Workflow после загрузки Assets дополнительно проверяет публичный latest endpoint и сообщает о старой версии/draft/prerelease вместо ложного успешного обновления.
- Приведено к единому форматированию содержимое ES modules, удалены лишняя обёртка фабрики манёвра и недостижимая старая ветка каталога фамильяров (она уже перенаправлялась в нативный менеджер), согласованы комментарии и технические сообщения. Проверка ESLint охватывает неиспользуемые переменные, повторные импорты, недостижимый код и повторные ключи.
- Обновлены README и релизная инструкция; добавлены проверки формата бонусных способностей, миграции, защиты пользовательских копий и устаревшего latest-манифеста.

## 0.16.1

- Добавлен собственный SF2e-компендиум `robot-customizations`: 36 Action Items, JSON-источники, текстовый снимок и готовый LevelDB. Каталог, сборка и runtime используют одну фабрику.
- Устранены отсутствующие источники Aquatic Adaptation, Armored Plates, Speakers и остальных записей каталога. Сохранение больше не зависит от одноимённых сторонних Items.
- Добавлены пассивные RE для 10 кастомизаций: скорости, чувства, HP за уровень и предметный бонус КД. Armored Plates использует нативный выбор +1/+2; ступень каталога не подменяет фактическое развитие.
- Остальные 26 Items содержат правила для ручного применения, без выдуманной автоматизации. Встроенная панель различает RE и ручное применение; последнее показывается информационным сообщением.
- Climber/Flier робота больше не разрешаются в одноимённые способности фамильяра с другой скоростью.
- Старый неверный источник неизменённого собственного Item обновляется на месте. Ручные, чужие и изменённые предметы защищены; точный нативный перенос собственной кастомизации не дублируется.
- Сохранены слоты, ограничения ступеней, обязательная Companion Compendia и необязательная интеграция Dailies. Действительно отсутствующие источники и превышение слотов по-прежнему сообщаются.
- Добавлены регрессионные проверки источников, безопасного обновления, повторной синхронизации, ручных копий и выбора Armored Plates; сборка охватывает пять LevelDB-паков и 89 Items.

## 0.16.0

- Добавлена необязательная интеграция с PF2e Dailies 4.23.1+ через публичный API: отдельный ежедневный набор 38 способностей Tech Core. Обязательная зависимость Companion Compendia не изменена.
- Подключение включается явно для владельца и фамильяра из раздела способностей или существующего инструмента управления, без новых кнопок в заголовках листов. Локальный редактор ежедневного набора скрывается при подключении.
- Стандартный набор фамильяра Dailies отключается только у выбранного владельца; при отключении интеграции прежняя настройка безопасно восстанавливается. Прочие наборы и владельцы не затрагиваются.
- Подготовка использует прежнюю безопасную синхронизацию: лимит, требования, стабильные UUID, отсутствие дубликатов, защита врождённых, ручных, сторонних и изменённых Items. Изменение состава, связи или лимита блокирует устаревший выбор.
- Добавлен обработчик отдыха Dailies для снятия только неизменённых собственных ежедневных Items. Чужие временные Items Dailies не присваиваются и не удаляются; перед переходом требуется штатный отдых.
- Без Dailies либо с несовместимым API доступен локальный выбор. Новые EN/RU-строки, документация, регрессионные проверки и упаковка runtime-файла. Состав компендиумов и механика самих способностей не изменены.

## 0.15.0

- Убраны кнопки модуля из заголовков листов и настройки их видимости; создание, связь и дополнительные инструменты перенесены в одно меню настроек модуля. API и сохранённые данные остаются доступными.
- В разделе способностей робота-компаньона добавлен встроенный выбор и замена улучшений: 36 записей, поиск, ступени, количество повторяемых улучшений, проверка слотов и сохранение ручных/неизвестных записей.
- В нативном разделе способностей фамильяра добавлен выбор ежедневного набора из 38 способностей. Защита врождённых, ручных и изменённых Items сохранена.
- Шасси скрыты из нативного ABCPicker родословных; компендиум и перетаскивание на character-компаньона сохранены. Каталог шасси стал справочным, без назначения кнопкой.
- Новые панели не добавляются обычным персонажам-владельцам. Права обоих акторов и изменение данных во время выбора проверяются перед сохранением; поля не передаются в системную форму актора.
- Окна ограничены размером экрана, содержимое и каталоги прокручиваются; кнопки остаются достижимыми.
- Обновлены EN/RU, документация, проверки профилей, фильтра родословных и релизной упаковки. Игровые правила шасси и состав четырёх компендиумов не изменены.

## 0.14.0

- Добавлено окно «Источники компаньонов и Pet» из Tech Pets и панели фамильяров: 13 источников SF2e, назначение, наличие на листе, открытие предмета и ссылки на правила.
- Лимиты Familiar / Enhanced Familiar / Incredible Familiar распознаются как 2/4/6 без сложения с системным лимитом. Ручной лимит сохраняет приоритет.
- Добавлен учёт целевых слотов Tactical/Advanced/Superior Drone и четырёх Customization. Дубликаты импорта не считаются повторными выборами; настоящие повторные Customization подтверждаются числом 1–3. Повтор Superior Drone не начисляет дополнительные слоты.
- Целевые слоты расходуются только на кастомизации каталога своей ступени. Старые явные правила и флаги слотов сохраняют приоритет, не начисляются повторно. Профили/Items пользователя не удаляются.
- Добавлен отдельный ручной профиль Pet с именем и двумя способностями категории Pet. Профиль не выдаёт черту и не создаёт ошибочно familiar-актора. Связь/создание фамильяра и активный Pet проверяются на конфликт.
- Добавлены подсказки о требованиях, несовместимости типов компаньонов, различии миниботов/турелей/курьерских дронов и настоящих источников, ручном развитии и лечении.
- EN/RU: 322 ключа. Расширены документные/mock-тесты; сохранены четыре готовых LevelDB-пака, прежние API и синхронизация.

## 0.12.0

- Добавлена отдельная панель «Фамильяры» на листе персонажа и нативного familiar. Используется уже существующий движок SF2e, без копирования классов PF2e и параллельного расчёта характеристик.
- Добавлены создание familiar с правами владельца, привязка через system.master, выбор характеристики и открытие системного листа. Занятый актор не перепривязывается молча.
- Новый собственный SF2e-компендиум familiar-abilities: 38 Action Items Tech Core с полными английскими описаниями, стабильными ID/slugs/sourceId и редактируемыми JSON-источниками.
- Для 10 пассивных способностей подготовлены сверенные Rule Elements; 28 остальных явно отмечены как ручные. Familiar Focus имеет стоимость 2 действия, но не восстанавливает ресурс автоматически.
- Добавлены ежедневный набор, системный/явный лимит, учёт вручную добавленных способностей и защита врождённых способностей. Повторяемый Skilled с разными навыками пока настраивается вручную.
- Добавлены поиск, просмотр описаний, открытие установленного предмета и отправка в чат. Импорт familiar-действий маршрутизируется к нативному фамильяру, не роботу.
- Проверяются основные зависимости между способностями и уровень для Kinspeech; остальные игровые требования проверяются пользователем.

- Старые записи robot.familiarAbilities и прежние предметы не стираются. Перенос в новый ежедневный набор требует подтверждения. Роботизированная синхронизация больше не создаёт familiar Items на character; прежние эффекты сохраняются для осознанной проверки.
- Добавлены совместимые API openFamiliar, createFamiliar, linkFamiliar, syncFamiliarAbilities; старые методы сохранены.
- Сборка и проверка воспроизводимости охватывают четыре настоящих LevelDB-пака (53 Items); JSONL .db остаются только текстовыми снимками.
- Интерфейс и сообщения EN/RU: 149 ключей. Описания правил в компендиуме английские.
- Расширены статические, mock- и браузерные проверки.

## 0.11.0

- Сохранены каталоги, интерфейс, данные профилей и прежние методы API.
- Обязательная зависимость pf2e-animal-companions остаётся minimum 7.6.3; сверены все 11 SF2e-ключей паков и реальный класс компаньона.
- Исправлены нативные поля ancestry: строковые size/vision, числовой speed, схемы boosts/flaws, полные пути навыков, аддитивные модификаторы вместо override.
- Добавлен GrantItem базового SF2e-класса; без доступного класса новое неполное шасси не создаётся.
- Уточнены Strikes, типы урона, range, traits и выбор размера.
- ChoiceSet использует настоящий flags.sf2e.rulesSelections; GrantItem получает стабильный flag, выбор размера не переименовывает Item и сбрасывается при смене шасси.
- Добавлен интерфейс Imitator: реальный совместимый источник, выбор конкретной безоружной атаки, сохранение размера/скоростей и атаки 1d4 agile/finesse. Неподдерживаемые источники отклоняются.
- Добавлен robot-support с пятью action-предметами. Три собственных пака содержат по пять Items.
- Манёвры выдаются на Advanced/Superior, не Commercial; переключатель не заменяет фиты ступени.
- Уточнена длительность поддержки Powerful; visual относится к Demoralize внутри Disturbing Display, не самому действию.
- Добавлены ссылки на состояния, отправка собственных действий в чат и явное предупреждение о ручном выполнении. Механика манёвров и поддержки не объявляется автоматизированной.
- Окна переведены на DialogV2; добавлены пункт ActorSheetV2 и штатное обогащение описаний TextEditor.
- Локализованы новые сообщения, подписи выбора размера и предупреждения; EN/RU имеют одинаковый набор ключей.
- Точный slug во всех подходящих паках ищется до имени; проверяются тип Item, система, PF2e-ссылки и ключи Rules.
- Исправлены учёт стоимости слотов, повторный импорт и повторное начисление слотов за один источник. Общий customization не даёт слот.
- Синхронизация сериализована; шасси обновляется на месте, повторный запуск сохраняет ID действий.
- Контрольные снимки защищают пользовательские изменения; старые Items без снимка, чужие контроллеры и ручные предметы не удаляются/перезаписываются.
- При недоступности источника сохраняются прежние предметы и записи. Заблокированное шасси не получает действия другого шасси.
- Усилена проверка self-link, циклов, занятого компаньона и обратной связи; старые self-link нормализуются как самостоятельный компаньон.
- Добавлен совместимый метод API linkActors; UI использует общую проверку связей.
- Вынесены общие фабрики Items и адаптер диалогов. Код отформатирован единообразно; комментарии к рабочей логике переведены на русский.
- Все три пака собираются официальным CLI в LevelDB с необходимыми _key, обратным извлечением и проверкой стабильных ID. JSON и текстовые .db сохранены.
- Добавлены статическая проверка, 10 тестов данных/паков и 28 mock-тестов.
- README дополнен установкой, миграцией, API и ограничениями; исправлена неверная оговорка об отсутствии текстов правил в архиве.
