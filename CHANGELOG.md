# Changelog

## 0.12.1

- Подготовлены GitHub CI и автоматическая сборка релизов: module.json, module.zip и SHA256SUMS.txt.
- Добавлены GitHub-ссылки, автор Huxtuntios, английский и русский README, инструкция выпуска через GitHub Desktop.
- Добавлен familiar-abilities в общую папку компендиумов.
- Очищена документация; журнал изменений начинается с 0.11.
- Сохранены описания границ автоматизации, защита данных и обязательная зависимость.

## 0.12.0

- Добавлена отдельная панель «Фамильяры» на листе персонажа и нативного familiar. Используется уже существующий движок SF2e, без копирования классов PF2e и параллельного расчёта характеристик.
- Добавлены создание familiar с правами владельца, привязка через system.master, выбор характеристики и открытие системного листа. Занятый актор не перепривязывается молча.
- Новый собственный SF2e-компендиум familiar-abilities: 38 Action Items Tech Core с полными английскими описаниями, стабильными ID/slugs/sourceId и редактируемыми JSON-источниками.
- Для 10 пассивных способностей подготовлены сверенные Rule Elements; 28 остальных явно отмечены как ручные. Familiar Focus имеет стоимость 2 действия, но не восстанавливает ресурс автоматически.
- Добавлены ежедневный набор, системный/явный лимит, учёт вручную добавленных способностей и защита врождённых способностей. Повторяемый Skilled с разными навыками пока настраивается вручную.
- Добавлены поиск, просмотр описаний, открытие установленного предмета и отправка в чат. Импорт familiar-действий маршрутизируется к нативному фамильяру, не роботу.
- Проверяются основные зависимости между способностями и уровень для Kinspeech; остальные игровые требования проверяются пользователем.
- Смена набора сериализуется, не дублирует ручные Items и не удаляет изменённые/сторонние/врождённые предметы. Снимки снимаются после нормализации системной схемой.
- Старые записи robot.familiarAbilities и прежние предметы не стираются. Перенос в новый ежедневный набор требует подтверждения. Роботизированная синхронизация больше не создаёт familiar Items на character; прежние эффекты сохраняются для осознанной проверки.
- Добавлены совместимые API openFamiliar, createFamiliar, linkFamiliar, syncFamiliarAbilities; старые методы сохранены.
- Сборка и проверка воспроизводимости охватывают четыре настоящих LevelDB-пака (53 Items); JSONL .db остаются только текстовыми снимками.
- Интерфейс и сообщения EN/RU: 149 ключей. Описания правил в компендиуме английские.
- Расширены статические, mock- и браузерные проверки.

## 0.11.0

- Сохранены каталоги, интерфейс, данные профилей и прежние методы API.
- Обязательная зависимость pf2e-animal-companions остаётся minimum 7.6.3; сверены все 11 SF2e-ключей паков и реальный класс компаньона.
- Исправлены нативные поля ancestry: строковые size/vision, числовой speed, схемы boosts/flaws, полные пути навыков, аддитивные модификаторы вместо override.
- Добавлен GrantItem базового SF2e-класса; без доступного класса новое неполное шасси не создаётся.
- Уточнены Strikes, типы урона, range, traits и выбор размера.
- ChoiceSet использует настоящий flags.sf2e.rulesSelections; GrantItem получает стабильный flag, выбор размера не переименовывает Item и сбрасывается при смене шасси.
- Добавлен интерфейс Imitator: реальный совместимый источник, выбор конкретной безоружной атаки, сохранение размера/скоростей и атаки 1d4 agile/finesse. Неподдерживаемые источники отклоняются.
- Добавлен robot-support с пятью action-предметами. Три собственных пака содержат по пять Items.
- Манёвры выдаются на Advanced/Superior, не Commercial; переключатель не заменяет фиты ступени.
- Уточнена длительность поддержки Powerful; visual относится к Demoralize внутри Disturbing Display, не самому действию.
- Добавлены ссылки на состояния, отправка собственных действий в чат и явное предупреждение о ручном выполнении. Механика манёвров и поддержки не объявляется автоматизированной.
- Окна переведены на DialogV2; добавлены пункт ActorSheetV2 и штатное обогащение описаний TextEditor.
- Локализованы новые сообщения, подписи выбора размера и предупреждения; EN/RU имеют одинаковый набор ключей.
- Точный slug во всех подходящих паках ищется до имени; проверяются тип Item, система, PF2e-ссылки и ключи Rules.
- Исправлены учёт стоимости слотов, повторный импорт и повторное начисление слотов за один источник. Общий customization не даёт слот.
- Синхронизация сериализована; шасси обновляется на месте, повторный запуск сохраняет ID действий.
- Контрольные снимки защищают пользовательские изменения; старые Items без снимка, чужие контроллеры и ручные предметы не удаляются/перезаписываются.
- При недоступности источника сохраняются прежние предметы и записи. Заблокированное шасси не получает действия другого шасси.
- Усилена проверка self-link, циклов, занятого компаньона и обратной связи; старые self-link нормализуются как самостоятельный компаньон.
- Добавлен совместимый метод API linkActors; UI использует общую проверку связей.
- Вынесены общие фабрики Items и адаптер диалогов. Код отформатирован единообразно; комментарии к рабочей логике переведены на русский.
- Все три пака собираются официальным CLI в LevelDB с необходимыми _key, обратным извлечением и проверкой стабильных ID. JSON и текстовые .db сохранены.
- Добавлены статическая проверка, 10 тестов данных/паков и 28 mock-тестов.
- README дополнен установкой, миграцией, API и ограничениями; исправлена неверная оговорка об отсутствии текстов правил в архиве.
