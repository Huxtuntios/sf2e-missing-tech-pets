## SF2e Missing Tech Pets 0.12.1

Tech Core robot companions and native familiar management for Starfinder Second Edition in Foundry VTT.

### Included content

- 5 Robot Chassis: Agile, Imitator, Powerful, Surveillance, and Tank.
- 5 Advanced Maneuvers and 5 Support Benefits.
- 38 Pet, Familiar, and Master ability Items from Tech Core.
- A catalog of 36 robot customizations.

### Features

- Master/companion links, chassis selection, size options, and Imitator configuration.
- Customization slot tracking and compatible SF2e compendium imports.
- A native familiar panel with creation, master linking, daily ability sets, and innate ability protection.
- Search, item inspection, chat descriptions, and protection for manual or edited Items.
- English and Russian interface; rules descriptions are primarily English.

### This release

- GitHub installation/update links and automated release assets.
- English and Russian README files and a GitHub Desktop release guide.
- All four compendiums grouped under the module's folder.

### Automation scope

Native Rule Elements are supplied for chassis mechanics and 10 passive familiar abilities. The other 28 familiar abilities, Advanced Maneuvers, Support Benefits, and choices described as manual still require manual resolution. The familiar panel does not grant a qualifying feat to the master.

### Requirements

- Foundry VTT v14, minimum 14.361.
- Starfinder Second Edition (`sf2e`) 1.6.0 or newer.
- **Required:** PF2e Companion Compendia (`pf2e-animal-companions`) 7.6.3 or newer, installed and active.

Use the **module.json** asset to install through Foundry. Do not use GitHub's automatic Source code archives as installation packages.
